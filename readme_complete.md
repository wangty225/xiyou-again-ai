```

  历史记录    创作要求     JSON数据    数据累积    光标效果
```

```json
{
    "chapters": [
        {
            "id": 1,

        },
        {
            "id": 14,
            "title": "收悟空",
            "filename": "chap14-收悟空.txt"
        }
    ]
}
```

### 获取章节详情

```http
GET /api/chapters/:id
```

**响应示例**：
```json
{
    "id": 14,
    "title": "收悟空",
    "content": "诗曰：佛即心兮心即佛，心佛从来皆妄物..."
}
```

### 流式故事生成

```http
POST /api/ai-agent/stream
Content-Type: application/json
```

**请求体**：
```json
{
    "character": {
        "id": "wukong",
        "name": "孙悟空",
        "role": "齐天大圣",
        "background": "...",
        "traits": ["勇敢", "机智", "忠诚"]
    },
    "step": 1,
    "userChoice": {
        "value": "protect",
        "text": "保护师父"
    },
    "storyHistory": [],
    "chapterId": 14,
    "chapterTitle": "收悟空"
}
```

**响应（SSE流）**：
```
data: {"text": "五"}

data: {"text": "百"}

data: {"text": "年"}

data: {"done": true, "parsedData": {...}}
```
